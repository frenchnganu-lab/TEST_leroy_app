# LEROY HOME CLUB — техкарта интерфейса v0.2

Основа: согласованный 20.10.2026 референс тёмного Telegram-кабинета с золотыми акцентами. Приоритет — мобильный экран от 360 px. Рамка телефона и системные индикаторы не входят в интерфейс.

## Дизайн

- Фон `#101110`, карточки `#1C1E1B`, акцент `#D7B77A`, текст `#F5F3ED`.
- Manrope, кириллица, крупные суммы и короткие подписи.
- Скругления 18–22 px, единый набор контурных SVG-иконок.
- Интерьерное изображение хранится локально в `frontend/public/images/club-kitchen.webp`.
- Шапка: меню, LEROY HOME CLUB, уведомления без фиктивного счётчика.
- Нижняя навигация: Главная, Проекты, Клиенты, Бонусы, Профиль; учтена безопасная область устройства.

## Главная

1. Явная маркировка демо или тестового кабинета.
2. Бонусы LR, текущий курс и рублёвый эквивалент, история операций.
3. Отдельная сумма начисленного денежного вознаграждения.
4. Уровень и прогресс в весах. В реальных данных прогресс отсутствует до интеграции расчёта. Демо содержит вымышленный пример.
5. Активные / завершённые проекты и сумма заказов без отменённых. Итоги SQL считаются по всем заказам; список ограничен 30 строками.
6. Информационный баннер программы привилегий, без вымышленной акции или срока.
7. События клуба: состояние без опубликованных событий.

## Разделы и поведение

| Раздел      | Поведение                                                                                                  |
| ----------- | ---------------------------------------------------------------------------------------------------------- |
| Проекты     | Фильтры Все / В работе / Завершены / Отменены; нажатие открывает номер, сумму, статус, дату сдачи          |
| Клиенты     | Пустое состояние «Раздел готовится», пока нет клиентской базы                                              |
| Бонусы      | Раздельные суммы RUB/LR; последние 30 операций; фильтр валюты; дата Красноярска и номер заказа при наличии |
| Профиль     | ФИО, уровень, ID, состояние входа; приглашения и правила программы                                         |
| Приглашения | Число связей invited_by и условия; ссылка/начисления не подключены                                         |
| Статус      | Пороговые веса тестовой модели: серебро 500, золото 2000, платина 5000; веса не равны LR                   |

Курс поступает из действующей записи reward_rules. В демо — 5 LR = 1 RUB.
Суммы обозначены «всего начислено», поскольку списания/выплаты ещё не реализованы.
Нет кнопок, обещающих вывод денег, автоматическое повышение или неподтверждённые привилегии.

## API

`GET /api/cabinet` после проверки подписи Telegram возвращает только данные разрешённого designer_id:

- designer, balance, projects, operations, referral_count;
- project_summary: active, delivered, total, total_amount_rub;
- rub_per_lr: актуальный курс либо null;
- loyalty: null до переноса расчёта весов;
- test_mode: true до разделения тестовых и рабочих операций.

Для текущего курса серверной роли требуется чтение reward_rules: новый проект использует `sql/01_cabinet_read_role.sql`; уже созданная роль — дополнительный `sql/02_cabinet_rate_access.sql`.

## Состояния и проверки

- Нет нулевого баланса во время загрузки; показывается skeleton.
- Ошибка входа не переключает пользователя на демо автоматически.
- Запросы отменяются при повторном входе/размонтировании.
- Модальные окна закрываются кнопкой, Escape и нажатием на фон; фокус ограничен диалогом.
- Проверено в Chromium: 5 разделов на 360, 390, 560, 1280 px, фильтры проектов/валют, карточка проекта и приглашения; без ошибок JS и горизонтальной прокрутки.
- Проверены TypeScript/Vite build и 12 серверных тестов. Подключение к реальному Telegram/Supabase проверяется отдельным этапом.
