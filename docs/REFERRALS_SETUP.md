# Регистрация по приглашению

Код подготовлен за флагом REFERRALS_ENABLED (по умолчанию false). Сначала применить sql/05_referral_registration.sql в Supabase SQL Editor от postgres, затем опубликовать код. Только после проверки SQL включить в Render:

- TELEGRAM_BOT_USERNAME=Leroy_app_bot
- REFERRALS_ENABLED=true

AUTO_REGISTRATION_ENABLED должно оставаться true. Никакие токены не меняются.

Ссылка имеет вид https://t.me/Leroy_app_bot?start=ref_D001. Для TG-* регистр ID сохраняется. ID не является секретом, ссылка не даёт доступа к кабинету. При открытии ссылки пользователь должен нажать Start. Бот сохраняет первую действительную ссылку в существующей registration_sessions на 24 часа. Контакт должен принадлежать отправителю; приглашение переносится в designers.invited_by только при создании нового дизайнера после подтверждения ФИО. Старые карточки не переатрибутируются. Отмена очищает сессию. Недействительная ссылка не мешает обычной регистрации.

Новые таблицы и страницы учёта не создаются. Миграция добавляет pending_referrer и этап contact к существующей служебной сессии. Старая SQL-функция остаётся для обратной совместимости. Начисления и веса не меняются.

Перед включением в рабочем режиме проверить на тестовой БД: начало по ссылке → свой контакт → ФИО → подтверждение; повтор webhook не создаёт вторую карточку; перезапуск приложения сохраняет приглашение; повторная ссылка не меняет первого пригласившего; отмена/истечение срока очищают приглашение; неактивный пригласивший не закрепляется; существующая карточка не получает нового пригласившего. Проверить новый ID в Make Supabase → Google и что поле invited_by перенесено в существующий столбец пригласившего. Пустое поле из Google не должно очищать invited_by в Supabase. Реальные начисления проверить отдельно текущим сценарием первого закрытого проекта; этот код не начисляет бонусов.

Локально пройдены Python unit/regression tests; DB integration tests требуют TEST_DATABASE_URL и не являются проверкой новой миграции. Сквозная проверка новой SQL-функции в Supabase обязательна перед включением флага.
