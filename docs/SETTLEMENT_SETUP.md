# Учёт выплат по строкам
На листе «база начислений» J — ручное начисление за проект в рублях. Для метки и реферала сумма рассчитывается автоматически. AA — сколько уже фактически выплатили по этой операции в рублях, включая предыдущие переводы. При выплате 50 ₽ и затем ещё 30 ₽ укажите сначала 50, затем 80. Денег Make не переводит. Отдельного столбца остатка в строке нет.

После миграций 08–11 сценарий 07 читает проверенные, переданные операции с идентификатором R и положительной суммой AA. Старые Y/Z — архив. Make вызывает record_sheet_paid_total с суммой подтверждённого начисления в исходной валюте (L для RUB, Q для LR) и с общим фактическим переводом AA в рублях. Для бонусов используется курс записи начисления. Повторы ничего не прибавляют; уменьшение суммы, переплата, другой источник и неверная точность отклоняются. Пустая ячейка не сторнирует выплату. Ошибочную подтверждённую выплату сверяйте с бухгалтерией отдельно.

settled_amount хранит накопительную выплату в исходной валюте; settled_at — момент полного закрытия. Итоги кабинета и база дизайнеров вычитают выплаченную часть из начисления. История показывает одно начисление и выплаченную по нему сумму, а не отдельные банковские переводы. Приветственные подарки без отдельной строки начисления по этой схеме не обрабатываются.
